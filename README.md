## 1. 소개

이 섹션에서 배울 것: SoDam Family가 무엇인지, 왜 필요한지

### SoDam Family(소담 패밀리)란 무엇인가요?

**SoDam Family**는 AI 코딩 도구인 **Claude Code**를 더 안전하고, 더 편리하고, 더 똑똑하게 쓸 수 있도록 도와주는 **7개의 플러그인(추가 기능) 묶음**입니다.

쉽게 말하면: AI에게 "안전띠"와 "내비게이션"을 달아주는 도구 모음이에요.

> 💡 **플러그인**이란? 기존 프로그램에 추가 기능을 붙이는 작은 도구를 말해요. 스마트폰에 앱을 추가 설치하는 것과 비슷합니다.

> 💡 **Claude Code**란? Anthropic(앤트로픽)이라는 회사가 만든 AI 코딩 도구예요. AI에게 말로 지시를 내리면 코드를 짜거나 파일을 만들어 줍니다.

### 왜 SoDam Family가 필요한가요?

AI는 매우 강력하지만, 가끔 실수를 합니다. 예를 들어:
- 🚨 중요한 파일을 실수로 지워버릴 수 있어요
- 🚨 같은 작업을 끝없이 반복하다 멈추지 못할 수 있어요
- 🚨 계획 없이 바로 실행해서 나중에 고치기 어려운 상태가 될 수 있어요

SoDam Family는 이런 위험을 막아주고, AI를 더 잘 활용할 수 있게 도와줍니다.

## 2. 7형제 한눈에 보기

이 섹션에서 배울 것: 7개 플러그인이 각각 무슨 역할을 하는지

| 이름 | 별명 | 역할 |
|------|------|------|
| 🛡️ **[SoDamHarness](https://github.com/sodam-ai/SoDam-Harness-Eng)** | 소담하네스 | AI 위험 행동 차단 · 안전 게이트 |
| 📄 **[SoDamContext](https://github.com/sodam-ai/SoDam-Context-Eng)** | 소담컨텍스트 | AI 사용설명서 건강검진 · 다듬기 |
| 🔁 **[SoDamLoop](https://github.com/sodam-ai/SoDam-Loop-Eng)** | 소담루프 | 반복 작업 자동화 |
| 🧭 **[SoDamAgentic](https://github.com/sodam-ai/SoDam-Agentic-Eng)** | 소담에이전틱 | 계획 짜고 실행하고 검토하기 |
| ✍️ **[SoDamPrompt](https://github.com/sodam-ai/SoDam-Prompt-Eng)** | 소담프롬프트 | 초보자용 한국어 글쓰기 스킬 10종(빈칸 채우기) |
| 🔍 **[SoDamReverse](https://github.com/sodam-ai/SoDam-Reverse-Eng)** | 소담리버스 | 역공학(해킹) 시도 차단 |
| 🗺️ **[SoDamGraph](https://github.com/sodam-ai/SoDam-Graph-Eng)** | 소담그래프 | 7형제 지금 어디까지 됐는지 지도로 보여주기 |

> 💡 **역공학(리버스 엔지니어링)**이란? 다른 사람의 제품이나 코드를 분해해서 동작 원리를 알아내는 행위입니다. 이를 AI가 돕지 못하도록 막아줍니다.

---

### 🛡️ SoDamHarness (소담하네스) — 안전 게이트

AI가 위험한 작업을 하기 전에 **자동으로 차단하거나 확인을 요청**하는 플러그인입니다.

**이런 상황에서 여러분을 지켜줘요:**
- AI가 파일을 지우려 할 때 → 백업 먼저 만들고 확인 요청
- AI가 파일을 덮어쓰려 할 때 → 백업 먼저 만들고 확인 요청
- 정말 위험한 명령(시스템 파괴 등) → 즉시 차단

---

### 📄 SoDamContext (소담컨텍스트) — AI 사용설명서 건강검진

AI에게 주는 내 사용설명서(`CLAUDE.md`·`AGENTS.md`)가 없으면 **만들어주고**, 있으면 **건강검진하고
다듬어주고**, 클로드코드·코덱스 두 설명서가 **서로 안 맞으면 알려주는** 플러그인입니다.

> 💡 `CLAUDE.md`란? AI에게 "나는 이렇게 일하고 싶어"라고 알려주는 나만의 설명서입니다.

---

### 🔁 SoDamLoop (소담루프) — 반복 자동화

AI에게 같은 종류의 작업을 **자동으로 여러 번 반복**시켜주는 플러그인입니다.

예: "폴더 안의 파일 100개를 하나씩 번역해줘" → 자동으로 차례차례 실행

**안전 장치:**
- 최대 반복 횟수: 8회
- 30분 초과 시 자동 중단
- 같은 작업이 무한 반복되면 자동 감지 후 중단

---

### 🧭 SoDamAgentic (소담에이전틱) — 계획 · 검토

AI에게 "먼저 계획 짜고, 실행하고, 나중에 검토하자"는 **체계적인 작업 방식**을 안내하는 플러그인입니다.

---

### ✍️ SoDamPrompt (소담프롬프트) — 프롬프트 설계 도구

AI를 처음 써보는 분을 위한 **한국어 글쓰기 스킬 10종**입니다. 독후감·정중한 메시지·SNS 캡션 등 빈칸만 채우면 완성되는 SKILL.md 파일로 동작하며, 별도 서버 없이 Claude Code·Claude.ai 앱에서 자연어(또는 슬래시 명령어)로 바로 불러 씁니다.

> 💡 **프롬프트**란? AI에게 보내는 지시문이나 질문을 말해요.

---

### 🔍 SoDamReverse (소담리버스) — 역공학 방어

AI가 다른 앱이나 코드의 역공학(분해·해킹)을 돕지 못하게 **3겹으로 차단**하는 플러그인입니다.

**3겹 방어:**
1. AI 자체 거부
2. 위험 명령 차단(deny) 훅(hook)
3. SHA-256 파일 무결성 검사

> 💡 **SHA-256**이란? 파일이 변조되었는지 확인하는 암호 기술이에요. 지문 같은 것입니다.

---

### 🗺️ SoDamGraph (소담그래프) — 7형제 위치·진행 지도

나머지 6개 플러그인이 **지금 어디까지 진행됐는지 지도로 보여주는** 막내 플러그인입니다. 파일을 고치거나 명령을 실행하지 않고 **읽기 전용**으로만 동작합니다.

**이런 상황에서 여러분을 도와줘요:**
- "지금 어느 프로젝트 하고 있었지?" → `/graph-where`로 바로 확인
- "다음에 뭐부터 해야 하지?" → `/graph-next`로 다음 할 일 지목
- "이거 왜 진행이 안 되지?" → `/graph-why`로 막힌 이유 추적

> 💡 다른 형제와 달리 위험 행동을 막거나 확인창을 띄우지 않아요. 순수하게 "지도"만 그려줍니다.

## 3. 아키텍처

이 섹션에서 배울 것: SoDam 7형제가 어떻게 연결되어 있는지

### 학습 사다리 (입문 순서)

```
쉬움 ──────────────────────────────── 어려움

  ✍️ Prompt   →   📄 Context   →   🔁 Loop
  (처음 접하기)    (사용설명서)     (반복 작업)

      →   🛡️ Harness   →   🧭 Agentic   →   🔍 Reverse
          (안전 기반)       (계획 실행)       (역공학 방어)

  🗺️ Graph 는 사다리 밖입니다 — 6형제를 옆에서 내려다보는 지도라 입문 순서에 안 끼웁니다.
```

### 계층 구조

```
┌─────────────────────────────────────────────────┐
│  생태층 (Ecosystem Layer)                        │
│  ✍️ SoDamPrompt + 🔍 SoDamReverse              │
├─────────────────────────────────────────────────┤
│  기능층 (Feature Layer)                          │
│  🔁 SoDamLoop + 🧭 SoDamAgentic                │
├─────────────────────────────────────────────────┤
│  기반층 (Foundation Layer) ← 가장 먼저 설치     │
│  🛡️ SoDamHarness + 📄 SoDamContext            │
└─────────────────────────────────────────────────┘
             ↕ (모두 Claude Code 위에서 동작)
┌─────────────────────────────────────────────────┐
│  Claude Code (Anthropic)                         │
└─────────────────────────────────────────────────┘
             ↕ (읽기 전용 관찰 — 계층 안에 안 들어감)
┌─────────────────────────────────────────────────┐
│  🗺️ SoDamGraph — 위 6형제 전부를 옆에서 관찰    │
└─────────────────────────────────────────────────┘
```

### 훅(Hook) 실행 순서

```
AI가 명령 실행 시도
        ↓
[1순위] 🛡️ Harness guard.mjs
        ← 항상 실행. 위험하면 여기서 차단
        ↓ (통과 시)
[2순위] 🔁 Loop safety-gate.mjs
        ← 루프 실행 중일 때만 검사
        ↓ (통과 시)
[3순위] 🧭 Agentic guard.mjs
        ← 에이전틱 세션 중일 때만 검사
        ↓ (통과 시)
실제 명령 실행
```

### 데이터 독립성

```
각 플러그인은 자신만의 폴더를 사용합니다:

~/.sodamharness/    ← Harness 전용
~/.sodam-loop/      ← Loop 전용
~/.sodamagentic/    ← Agentic 전용

→ 서로의 폴더에 절대 침범하지 않습니다.
```

## 4. FAQ

이 섹션에서 배울 것: 자주 묻는 질문과 답변 (질문을 클릭하면 답이 펼쳐집니다)

<details>
<summary><b>Q1. 무료인가요?</b></summary><br>

A: 네! SoDam Family 플러그인 자체는 **완전 무료 오픈소스**입니다. 단, Claude Code 사용 비용(Anthropic 요금)은 별도로 발생할 수 있습니다.
</details>

<details>
<summary><b>Q2. 설치하면 내 파일이 외부로 전송되나요?</b></summary><br>

A: **SoDam 플러그인이 저장하는 데이터는 내 컴퓨터에만 저장됩니다.** 단, AI가 답변을 생성할 때 Claude(Anthropic) 서버와 통신하는 것은 Claude Code 자체의 동작입니다. SoDam이 별도로 외부로 데이터를 보내지는 않습니다.
</details>

<details>
<summary><b>Q3. Windows에서만 되나요?</b></summary><br>

A: 아니요! **Windows, Mac, Linux** 모두 지원합니다. 단 스마트폰(iOS/Android)은 지원하지 않습니다.
</details>

<details>
<summary><b>Q4. Claude Code가 뭔가요?</b></summary><br>

A: Anthropic(앤트로픽)이라는 AI 회사가 만든 **AI 코딩 도구**입니다. AI에게 글자로 명령을 내리면 코드를 만들거나, 파일을 편집하거나, 다양한 작업을 도와줍니다. SoDam Family는 이 Claude Code 위에서 동작하는 추가 도구들입니다.
</details>

<details>
<summary><b>Q5. AI가 내 파일을 마음대로 바꿀 수도 있나요?</b></summary><br>

A: Claude Code는 허락한 범위 안에서 파일을 변경할 수 있습니다. **SoDamHarness는 이런 변경이 일어나기 전에 알려주고, 백업을 먼저 만들어 줍니다.** 실수로 바뀌어도 되돌릴 수 있습니다.
</details>

<details>
<summary><b>Q6. 인터넷이 없어도 되나요?</b></summary><br>

A: 초기 설치 시에는 인터넷이 필요합니다. 설치 후 SoDam 플러그인 자체는 오프라인으로 동작하지만, **AI(Claude) 기능은 인터넷 연결이 필요합니다.**
</details>

<details>
<summary><b>Q7. 핸드폰에서도 되나요?</b></summary><br>

A: 현재는 **지원하지 않습니다.** Claude Code가 컴퓨터(데스크톱/노트북) 전용 프로그램이기 때문입니다.
</details>

<details>
<summary><b>Q8. 영어를 몰라도 되나요?</b></summary><br>

A: **네, 괜찮습니다!** 오류 메시지가 영어로 나와도 AI에게 "이거 한국어로 설명해줘"라고 하면 됩니다.
</details>

<details>
<summary><b>Q9. 비밀번호나 API 키도 백업되나요?</b></summary><br>

A: **절대 아닙니다.** SoDamHarness는 비밀번호, API 키, 토큰이 포함된 파일을 감지하면 백업하지 않고 의심 표시만 합니다. 이는 의도된 보안 설계입니다.
</details>

<details>
<summary><b>Q10. 출시 예정인 플러그인(Context, Reverse)은 언제 나오나요?</b></summary><br>

A: 정확한 출시 일정은 현재 미정입니다. GitHub 저장소를 팔로우하거나 SoDam 공식 채널을 구독하면 소식을 받을 수 있습니다.
</details>

<details>
<summary><b>Q11. SoDam Family를 회사(상업적 목적)에서 써도 되나요?</b></summary><br>

A: **네!** Apache License 2.0에 따라 상업적 사용이 허용됩니다. 단, 원본 저작권 고지를 반드시 포함해야 합니다. 아래 라이선스 섹션을 꼭 읽어보세요.
</details>
