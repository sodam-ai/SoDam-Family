## 1. 소개

이 섹션에서 배울 것: SoDam Family가 무엇인지, 왜 필요한지

### SoDam Family(소담 패밀리)란 무엇인가요?

**SoDam Family**는 AI 코딩 도구인 **Claude Code**를 더 안전하고, 더 편리하고, 더 똑똑하게 쓸 수 있도록 도와주는 **6개의 플러그인(추가 기능) 묶음**입니다.

쉽게 말하면: AI에게 "안전띠"와 "내비게이션"을 달아주는 도구 모음이에요.

> 💡 **플러그인**이란? 기존 프로그램에 추가 기능을 붙이는 작은 도구를 말해요. 스마트폰에 앱을 추가 설치하는 것과 비슷합니다.

> 💡 **Claude Code**란? Anthropic(앤트로픽)이라는 회사가 만든 AI 코딩 도구예요. AI에게 말로 지시를 내리면 코드를 짜거나 파일을 만들어 줍니다.

### 왜 SoDam Family가 필요한가요?

AI는 매우 강력하지만, 가끔 실수를 합니다. 예를 들어:
- 🚨 중요한 파일을 실수로 지워버릴 수 있어요
- 🚨 같은 작업을 끝없이 반복하다 멈추지 못할 수 있어요
- 🚨 계획 없이 바로 실행해서 나중에 고치기 어려운 상태가 될 수 있어요

SoDam Family는 이런 위험을 막아주고, AI를 더 잘 활용할 수 있게 도와줍니다.

## 2. 6형제 한눈에 보기

이 섹션에서 배울 것: 6개 플러그인이 각각 무슨 역할을 하는지

| 이름 | 별명 | 역할 | 상태 |
|------|------|------|------|
| 🛡️ **SoDamHarness** | 소담하네스 | AI 위험 행동 차단 · 안전 게이트 | ✅ 완료 |
| 📄 **SoDamContext** | 소담컨텍스트 | AI 사용설명서 건강검진 · 다듬기 | 🔜 예정 |
| 🔁 **SoDamLoop** | 소담루프 | 반복 작업 자동화 | ✅ 완료 |
| 🧭 **SoDamAgentic** | 소담에이전틱 | 계획 짜고 실행하고 검토하기 | ✅ 완료 |
| ✍️ **SoDamPrompt** | 소담프롬프트 | 더 좋은 AI 지시문(프롬프트) 설계 | 🔜 예정 |
| 🔍 **SoDamReverse** | 소담리버스 | 역공학(해킹) 시도 차단 | 🔜 예정 |

> 💡 **역공학(리버스 엔지니어링)**이란? 다른 사람의 제품이나 코드를 분해해서 동작 원리를 알아내는 행위입니다. 이를 AI가 돕지 못하도록 막아줍니다.

---

### 🛡️ SoDamHarness (소담하네스) — 안전 게이트

AI가 위험한 작업을 하기 전에 **자동으로 차단하거나 확인을 요청**하는 플러그인입니다.

**이런 상황에서 여러분을 지켜줘요:**
- AI가 파일을 지우려 할 때 → 백업 먼저 만들고 확인 요청
- AI가 파일을 덮어쓰려 할 때 → 백업 먼저 만들고 확인 요청
- 정말 위험한 명령(시스템 파괴 등) → 즉시 차단

**현재 상태:** ✅ 자가테스트 72개 모두 통과

---

### 📄 SoDamContext (소담컨텍스트) — AI 사용설명서 건강검진

AI에게 주는 내 사용설명서(`CLAUDE.md` 등)가 잘 작성되어 있는지 **건강검진하고 다듬어주는** 플러그인입니다.

> 💡 `CLAUDE.md`란? AI에게 "나는 이렇게 일하고 싶어"라고 알려주는 나만의 설명서입니다.

**현재 상태:** 🔜 출시 예정 (v0.1.0 구현 완료 · 공개 배포 준비 중)

---

### 🔁 SoDamLoop (소담루프) — 반복 자동화

AI에게 같은 종류의 작업을 **자동으로 여러 번 반복**시켜주는 플러그인입니다.

예: "폴더 안의 파일 100개를 하나씩 번역해줘" → 자동으로 차례차례 실행

**안전 장치:**
- 최대 반복 횟수: 8회
- 30분 초과 시 자동 중단
- 같은 작업이 무한 반복되면 자동 감지 후 중단

**현재 상태:** ✅ 자가테스트 17개 모두 통과

---

### 🧭 SoDamAgentic (소담에이전틱) — 계획 · 검토

AI에게 "먼저 계획 짜고, 실행하고, 나중에 검토하자"는 **체계적인 작업 방식**을 안내하는 플러그인입니다.

**현재 상태:** ✅ 자가테스트 22개 모두 통과

---

### ✍️ SoDamPrompt (소담프롬프트) — 프롬프트 설계 도구

AI에게 더 좋은 지시문(프롬프트)을 만들 수 있도록 **웹 브라우저에서 사용하는 도구**입니다.

> 💡 **프롬프트**란? AI에게 보내는 지시문이나 질문을 말해요.

**현재 상태:** ✅ v0.1.0 구현 완료 (한국어 글쓰기 스킬 10종, 무코드 SKILL.md · 2026-06 웹앱 계획은 폐기됨)

---

### 🔍 SoDamReverse (소담리버스) — 역공학 방어

AI가 다른 앱이나 코드의 역공학(분해·해킹)을 돕지 못하게 **3겹으로 차단**하는 플러그인입니다.

**3겹 방어:**
1. AI 자체 거부
2. 위험 명령 차단(deny) 훅(hook)
3. SHA-256 파일 무결성 검사

> 💡 **SHA-256**이란? 파일이 변조되었는지 확인하는 암호 기술이에요. 지문 같은 것입니다.

**현재 상태:** 🔜 출시 예정 (v0.1.0 구현 완료 · 공개 배포 준비 중)

## 3. 사전 준비물 & 필요 프로그램

이 섹션에서 배울 것: 설치하기 전에 무엇이 필요한지

### ✅ 필요한 것 체크리스트

- [ ] **인터넷 연결** — 설치 시 필요 (이후에는 오프라인 가능)
- [ ] **컴퓨터** — Windows, Mac, Linux 모두 가능 (스마트폰은 불가)
- [ ] **Node.js v18 이상** — 무료 프로그램 (아래 설명 참고)
- [ ] **Claude Code** — Anthropic 공식 AI 코딩 도구

> 💡 **Node.js**란? 자바스크립트(프로그래밍 언어)를 컴퓨터에서 실행할 수 있게 해주는 무료 프로그램입니다.

---

### Node.js 설치하기

1. 브라우저에서 **https://nodejs.org** 접속
2. 녹색 버튼 **"LTS"** 클릭 (LTS = 안정적인 버전)
3. 다운로드된 파일 실행 → "다음" 계속 클릭 → 설치 완료

**설치 확인 방법:**
```
터미널(명령 프롬프트)을 열고 아래를 입력하세요:
node --version
```
`v18.0.0` 이상의 숫자가 나오면 성공입니다! ✅

> 💡 **터미널(명령 프롬프트)**이란? 컴퓨터에게 글자로 명령을 내리는 창입니다. Windows는 `Windows키 + R` → `cmd` 입력, Mac은 `Spotlight(돋보기)` → `terminal` 입력

---

### Claude Code 설치하기

1. **https://claude.ai/code** 접속
2. 화면 안내에 따라 설치
3. Anthropic 계정이 없으면 먼저 회원가입 필요

> ⚠️ **주의:** Claude Code 사용에는 Anthropic 요금이 발생할 수 있습니다. 무료 플랜이 있으니 먼저 확인해 보세요.

## 8. 사용 방법

이 섹션에서 배울 것: 각 플러그인을 실제로 어떻게 쓰는지

### 🛡️ SoDamHarness 사용 방법

**평소에는:** 아무것도 안 해도 됩니다. AI가 위험한 행동을 하면 자동으로 알려줍니다.

**알림이 뜨면:**
- `Y` 또는 `허용` → 진행
- `N` 또는 `취소` → 중단

**백업에서 파일 되살리기:**
```
/sodam-harness-undo
```

**AI가 매번 물어봐서 불편할 때 (이번 세션만 신뢰 모드):**
```
/sodam-harness-trust
```

**AI가 뭘 했는지 확인하고 싶을 때:**
```
/sodam-harness-log
```

---

### 🔁 SoDamLoop 사용 방법

**반복 작업 시작:**
```
/sodam-loop-start
```
그 다음 AI에게 말하세요: "폴더 안의 파일들을 하나씩 번역해줘"

**진행 상황 확인:**
```
/sodam-loop-status
```

**중간에 멈추고 싶을 때:**
```
/sodam-loop-cancel
```

**뭔가 잘못됐을 때:**
```
/sodam-loop-undo
```

---

### 🧭 SoDamAgentic 사용 방법

**계획 모드 시작:**
```
/sodam-agentic-start
```

**계획 짜기:**
```
/sodam-agentic-plan
```
AI가 먼저 계획을 세우고 확인을 받습니다.

**결과 검토:**
```
/sodam-agentic-review
```
작업이 끝난 후 잘 됐는지 확인합니다.

## 9. 작동 방법

이 섹션에서 배울 것: SoDam이 내부적으로 어떻게 동작하는지 (보안 · 데이터 흐름 포함)

### 어떻게 위험을 감지하나요?

SoDam은 **훅(Hook)**이라는 방식으로 동작합니다.

> 💡 **훅(Hook)**이란? Claude Code가 어떤 작업을 실행하기 전·후에 자동으로 실행되는 검사 프로그램입니다. "낚싯바늘"처럼 작업을 잠깐 잡아둡니다.

**훅 실행 순서:**
```
AI가 명령을 실행하려 할 때:
  1단계: Harness guard.mjs 검사 (항상 실행 · 1순위)
  2단계: Loop safety-gate.mjs (루프 실행 중일 때만)
  3단계: Agentic guard.mjs (에이전틱 세션 중일 때만)
```

### 3가지 반응 방식

| 상황 | 반응 | 설명 |
|------|------|------|
| 정말 위험한 명령 | 🔴 차단(deny) | 실행 자체를 막음 |
| 파일 삭제 · 덮어쓰기 | 🟡 확인(ask) | 백업 후 사용자에게 확인 요청 |
| 안전한 작업 | 🟢 통과(allow) | 바로 실행 |

### 데이터는 어디에 저장되나요?

```
내 컴퓨터 안에만 저장됩니다!

~/.sodamharness/         ← Harness 데이터
~/.sodam-loop/           ← Loop 데이터
~/.sodamagentic/         ← Agentic 데이터
~/.sodamharness/backups/ ← Harness 백업
~/.sodam-loop/backups/   ← Loop 백업
```

> ⚠️ **주의:** AI가 답변을 생성할 때는 Claude(Anthropic) 서버와 통신합니다. 이는 SoDam이 아닌 Claude Code 자체의 동작입니다.

### 보안 원칙

- ✅ **내 컴퓨터에만 저장** (SoDam 플러그인 데이터)
- ✅ **비밀번호·API 키는 절대 백업하지 않음** (의심 표시만)
- ✅ **원자적 쓰기** — 파일을 임시 이름으로 먼저 저장 → 완료 후 최종 이름으로 변경 (중간에 꺼져도 파일 손상 없음)
- ✅ **타임스탬프 백업** — 백업 폴더명에 날짜·시간 포함 (예: `backup_20260628_143022`)
- ✅ **각 플러그인 독립** — 서로의 폴더에 침범하지 않음

## 14. 문제 & 오류 대처 방법

이 섹션에서 배울 것: 뭔가 잘못됐을 때 어떻게 해결하는지

> 💡 걱정 마세요! 대부분의 문제는 아래 방법으로 해결됩니다.

---

### ❌ 문제 1: 명령어를 입력했는데 아무 반응이 없어요

**원인:** 플러그인이 제대로 설치되지 않았거나 Claude Code가 재시작되지 않았어요.

**해결 방법:**
```
1. Claude Code를 완전히 종료합니다
   (트레이 아이콘 우클릭 → 종료)
2. 다시 시작합니다
3. /sodam-harness-status 입력하여 확인
```

---

### ❌ 문제 2: "플러그인을 찾을 수 없습니다" 오류

**해결 방법:**
```
1. /sodam-harness-fix 입력
2. 안내에 따라 진행
3. 그래도 안 되면: 플러그인 폴더 경로를 다시 확인
```

---

### ❌ 문제 3: Harness가 너무 자주 물어봐서 불편해요

**해결 방법:**
```
/sodam-harness-trust
```
이번 세션 동안 반복 질문을 줄여줍니다.

> ⚠️ Claude Code를 껐다 켜면 다시 원래 상태로 돌아옵니다. 이것이 정상입니다.

---

### ❌ 문제 4: 루프(Loop)가 멈추지 않아요

**해결 방법:**
```
/sodam-loop-cancel
```
그래도 멈추지 않으면:
```
Claude Code를 완전히 종료합니다.
```
> ✅ 루프는 최대 8회, 30분이 넘으면 자동으로 중단됩니다.

---

### ❌ 문제 5: node --version 명령어가 작동 안 해요

**해결 방법:**
1. https://nodejs.org 에서 LTS 버전 재설치
2. 설치 후 터미널(명령 프롬프트)을 **새로 열기**
3. 다시 `node --version` 입력

---

### ❌ 문제 6: 파일이 잘못 바뀌었어요

**해결 방법:**
```
/sodam-harness-undo
```
백업 목록에서 원하는 시점을 선택하면 복구됩니다.

---

### ❌ 문제 7: 설치했는데 오류 메시지가 영어로 나와요

걱정 마세요! 오류 메시지를 **그대로 복사**해서 Claude Code에 붙여넣고 이렇게 물어보세요:
```
이 오류 메시지를 한국어로 설명해주고 해결 방법을 알려줘:
[오류 메시지 붙여넣기]
```

---

### ❌ 문제 8: Agentic이 계획을 무시하고 바로 실행해요

이것은 **알려진 한계**입니다. Phase 2에서 개선 예정입니다.

## 15. FAQ

이 섹션에서 배울 것: 자주 묻는 질문과 답변

---

**Q1. 무료인가요?**

A: 네! SoDam Family 플러그인 자체는 **완전 무료 오픈소스**입니다. 단, Claude Code 사용 비용(Anthropic 요금)은 별도로 발생할 수 있습니다.

---

**Q2. 설치하면 내 파일이 외부로 전송되나요?**

A: **SoDam 플러그인이 저장하는 데이터는 내 컴퓨터에만 저장됩니다.** 단, AI가 답변을 생성할 때 Claude(Anthropic) 서버와 통신하는 것은 Claude Code 자체의 동작입니다. SoDam이 별도로 외부로 데이터를 보내지는 않습니다.

---

**Q3. 잘못 설치하면 어떻게 되나요?**

A: 걱정 마세요! 아래 명령어로 깔끔하게 제거할 수 있습니다:
```
/sodam-loop-uninstall
```
Harness와 Agentic도 같은 방식으로 제거 가능합니다.

---

**Q4. Windows에서만 되나요?**

A: 아니요! **Windows, Mac, Linux** 모두 지원합니다. 단 스마트폰(iOS/Android)은 지원하지 않습니다.

---

**Q5. Harness 없이 Loop만 설치해도 되나요?**

A: 기술적으로는 가능하지만 **권장하지 않습니다.** Harness가 안전 기반을 제공하기 때문에 Harness를 먼저 설치하는 것을 강력히 추천합니다. Harness 없이 Loop를 사용하면 반복 작업 중 파일이 잘못 바뀌어도 보호받지 못합니다.

---

**Q6. 오류가 나서 멈췄어요. 어떻게 하나요?**

A: 3단계로 해결해보세요:
1. `/sodam-harness-fix` 입력
2. Claude Code 완전 종료 후 재시작
3. 오류 메시지를 복사해서 AI에게 한국어 설명 요청

---

**Q7. 백업은 얼마나 보관되나요?**

A: 현재는 **자동 삭제 기능이 없습니다.** 즉, 수동으로 지우지 않는 한 계속 보관됩니다. 백업 폴더(`~/.sodamharness/backups/`)가 너무 커지면 직접 오래된 것을 삭제하세요.

---

**Q8. 동시에 여러 개 설치해도 되나요?**

A: 네! **모두 동시에 설치해도 됩니다.** 각 플러그인은 독립적으로 동작하고 서로 충돌하지 않도록 설계되었습니다.

---

**Q9. Claude Code가 뭔가요?**

A: Anthropic(앤트로픽)이라는 AI 회사가 만든 **AI 코딩 도구**입니다. AI에게 글자로 명령을 내리면 코드를 만들거나, 파일을 편집하거나, 다양한 작업을 도와줍니다. SoDam Family는 이 Claude Code 위에서 동작하는 추가 도구들입니다.

---

**Q10. AI가 내 파일을 마음대로 바꿀 수도 있나요?**

A: Claude Code는 허락한 범위 안에서 파일을 변경할 수 있습니다. **SoDamHarness는 이런 변경이 일어나기 전에 알려주고, 백업을 먼저 만들어 줍니다.** 실수로 바뀌어도 `/sodam-harness-undo`로 되살릴 수 있습니다.

---

**Q11. 인터넷이 없어도 되나요?**

A: 초기 설치 시에는 인터넷이 필요합니다. 설치 후 SoDam 플러그인 자체는 오프라인으로 동작하지만, **AI(Claude) 기능은 인터넷 연결이 필요합니다.**

---

**Q12. 핸드폰에서도 되나요?**

A: 현재는 **지원하지 않습니다.** Claude Code가 컴퓨터(데스크톱/노트북) 전용 프로그램이기 때문입니다.

---

**Q13. 영어를 몰라도 되나요?**

A: **네, 괜찮습니다!** 명령어는 외워야 하지만 이 문서를 참고하면 됩니다. 오류 메시지가 영어로 나와도 AI에게 "이거 한국어로 설명해줘"라고 하면 됩니다.

---

**Q14. 업데이트는 어떻게 하나요?**

A: GitHub에서 최신 버전을 받아 같은 방법으로 재설치하면 됩니다:
```
git pull origin main
```
(설치한 폴더 안에서 실행)

이후 Claude Code 완전 종료 후 재시작하면 새 버전이 적용됩니다.

---

**Q15. 삭제(제거)하면 내 파일도 지워지나요?**

A: **아니요!** 플러그인을 제거해도 원본 파일은 전혀 건드리지 않습니다. 단, SoDam 자체 데이터 폴더(`~/.sodamharness/`, `~/.sodam-loop/` 등)는 수동으로 삭제해야 완전히 제거됩니다.

---

**Q16. Loop의 최대 반복 횟수를 늘릴 수 있나요?**

A: 현재 버전에서는 **최대 8회**로 고정되어 있습니다. 이는 무한 루프로 인한 사고를 막기 위한 안전 장치입니다. 더 많은 반복이 필요하면 루프를 다시 시작하세요.

---

**Q17. 비밀번호나 API 키도 백업되나요?**

A: **절대 아닙니다.** SoDamHarness는 비밀번호, API 키, 토큰이 포함된 파일을 감지하면 백업하지 않고 의심 표시만 합니다. 이는 의도된 보안 설계입니다.

---

**Q18. SoDamLoop 중에 루프가 이상하게 반복돼요. 버그인가요?**

A: Loop는 **오실레이션(같은 작업 무한 반복) 감지 기능**이 있어 자동으로 중단합니다. 중단됐다면 `/sodam-loop-repair`를 실행해 원인을 확인하세요.

---

**Q19. 출시 예정인 플러그인(Context, Prompt, Reverse)은 언제 나오나요?**

A: 정확한 출시 일정은 현재 미정입니다. GitHub 저장소를 팔로우하거나 SoDam 공식 채널을 구독하면 소식을 받을 수 있습니다.

---

**Q20. SoDam Family를 회사(상업적 목적)에서 써도 되나요?**

A: **네!** Apache License 2.0에 따라 상업적 사용이 허용됩니다. 단, 원본 저작권 고지를 반드시 포함해야 합니다. 아래 라이선스 섹션을 꼭 읽어보세요.
